# Back-office company's Card specifications

Card UI is similar to component-card-dossier. Each card represent a company.

Dossier's Card props :

- title : Company name
- subtitle : User's full name
- right : Clickable Button "Gérer" redirect to relevant page-entreprise.

The visual (thin wide card, title/subtitle/optional right-hand button) is shared with
component-card-colleague via the `EntityCard` primitive.
