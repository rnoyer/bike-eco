# Back-office Registered companies page specifications

This page reuse the same UI as the Dashboard : same UI sections, lookalike cards

## Navbar props

Left : left arrow (Back to Dashborad page)
middle : "Vendeurs enregistrées"
right : none

## Main section

From top to Bottom :

- Section "Vendeurs a valider" props :
  - Title : "Vendeurs a valider"
  - List of cards "Company" ordered by the date of submission (older on top)
  - Message if no entries : "Pas de vendeur a valider pour le moment."
- Section "Vendeurs enregistrées" props :
  - Title : "Vendeurs enregistrées"
  - List of cards "Company" ordered by the date of validation (most recent on top)
  - Message if no entries : "Pas de vendeur enregistrée pour le moment."
